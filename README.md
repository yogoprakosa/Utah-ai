# Utah AI — Final Source Project

A complete Android project foundation for Utah AI:
- Kotlin + Jetpack Compose
- Functional chat UI wired to a backend endpoint
- Backend proxy using OpenAI Responses API
- Camera/microphone permissions reserved for multimodal and voice features
- API key kept server-side

This is source code, not a precompiled APK. The final APK must be built with Android SDK/Gradle.
